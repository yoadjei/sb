PROJECT OVERVIEW

The Digital Sports Scoreboard is a portable Bluetooth-controlled electronic scoreboard designed for indoor and outdoor sporting events.

The scoreboard:

• Displays Team A name
• Displays Team B name
• Displays Team A score
• Displays Team B score

The operator controls everything from the mobile application.

Additional features include:

• Bluetooth communication with ESP32
• Start Game
• End Game
• Reset Game
• Audio announcements (played by DFPlayer Mini on ESP32)
• Automatic LCD brightness using an LDR
• Rechargeable battery powered by solar or charger

The mobile app only sends commands.

The ESP32 performs the hardware actions.

This matches the project design document, including Bluetooth control, score updates, team names, game controls, reset functionality, and interaction with the ESP32.
